# Rustic – Inspired Kitchen

Website for **Rustic – Inspired Kitchen**, a fine-dining restaurant in C-Scheme, Jaipur - North Indian and Mughlai menu, gallery and reservation enquiries.

## Tech stack

- React 19 + Vite 8 (TypeScript)
- Tailwind CSS 4
- lucide-react icons

## Getting started

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Structure

```
src/         pages, components and styles
public/      images and static assets
index.html   entry HTML
```
